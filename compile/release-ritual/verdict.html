Read this before you read the PASS

⚠ The evidence is DIRECTIONAL, not PROVEN

Five fair scenarios would earn PROVEN if every metric were provenance-backed and the surface set were uniformly independent. It is not — two disclosures:

  • Two of the nine compared surfaces cannot fail. CHANGELOG.md and COORD.md are de-shipped by removing the section and the line the ritual writes, then the ritual puts them back — round-trip identities by construction. They prove the insertion point, ordering and whitespace. They do not prove the prose, and they cannot fail. The tool labels them round-trip in its own output for exactly this reason.
  • Two more surfaces are written but never compared. The repo-root README.md and CLAUDE.md numerals are rewritten by the count clause and excluded from parity — no historical ship kept them in sync, so comparing them would fail every replay for a defect that predates the script.

An earlier draft claimed a flat “5/5 PARITY PASS” with neither disclosure. The independent refuter lane caught it — that overclaim was one of three confirmed criticals, alongside a tombstone de-pin that committed at exit 0 and a validator failure string-matched into “CLI absent → proceed”. All 15 findings were fixed in one bounded repair round; the seat re-ran both critical repros itself.

Recommendation

Adopt at USE IT, gated — before considering INSTALL IT.

Run the next real release through ship.py without --push and without --install. Inspect the commit it produces, then push by hand. That converts the one gap that matters — the runtime has never done a real ship — into evidence, at the cost of one manual push, with the old path warm behind it and a git checkout -- rollback armed if anything aborts.

Two fixes before full adoption, neither blocking a gated first use: (1) assert version monotonicity — ship --version 3.1.1 on a 3.3.0 tree currently succeeds; (2) either bring the root README.md/CLAUDE.md numerals into the parity set or state permanently that the count clause writes six surfaces and proves four.
