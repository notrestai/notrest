**Session Harness — hands-on workshop**

Everyone who uses an AI coding agent long enough hits the same four failures: sessions that
look set up but aren't, "done" that turns out not to be, context lost the moment a session
ends, and delegated work nobody can audit. This workshop names all four, shows each one
happening live, then hands attendees the tool that answers it — one at a time, with everyone
driving on their own laptop.

It ends with attendees deliberately shutting down a session and continuing the same piece of
work from a fresh one that has never seen it.
