# Not Rest Inc. — Codex + Claude working-session harness

The **`notrest`** plugin marketplace by [Not Rest Inc.](https://do.not.rest).

## Install on Claude

```
/plugin marketplace add notrestai/notrest
/plugin install notrest@notrest
```

**Renaming from `oracle-suite`?** Same harness, new id — the plugin was renamed `oracle-suite` → `notrest`
(the marketplace is still `notrest`, so the install id is now `notrest@notrest` and skills invoke as
`/notrest:<name>`). Install `notrest` as above, then drop the old entry:

```
claude plugin uninstall oracle-suite
```

## Install on Codex (local source build)

This repo carries a native Codex manifest at
`plugins/notrest/.codex-plugin/plugin.json` and a repo-local catalog at
`.agents/plugins/marketplace.json`. Add this repo as the local marketplace, install
`notrest@notrest-codex-local`, then start a **new Codex task** so skill discovery reloads.

The Codex adapter writes `AGENTS.md`, uses explicit `gpt-5.6-sol` workers when delegation
is authorized, and checks Codex's own install inventory. It does not claim Claude's
SessionStart/UserPromptSubmit/SubagentStop hooks run on Codex. See
`plugins/notrest/docs/CODEX.md` for the exact capability map.

## Plugins

### notrest (`notrest`)
**The session harness** — the scaffolding a working session runs inside: runtime foundation +
explicit instruments, delegation as an arrangement (agentswarm) with a spend ledger that makes the model-routing
policy checkable, an append-only estate that records every prompt and every agent, continuity + successor
escort across sessions, and an eval suite the harness runs against its own rules. Thirty-two skills ride
on it — structured thinking from intake to handoff, built on three principles: **token-lean** (progressive disclosure, `--quick` modes, built-in search budgets), **verified** (real tiered sources, disconfirmation passes, honesty labels on every claim), and **model-agnostic** (the discipline lives in the skills, so any model runs them reliably):

| Skill | What it does |
|---|---|
| **oracle** | Session intake — six setup questions + loads/creates the runtime foundation (`AGENTS.md` on Codex, `CLAUDE.md` on Claude). |
| **notrest** | The **establishment + continuation verb** — writes `COORD.md` plus a marker-delimited **v3** protocol block in `AGENTS.md` (Codex), `CLAUDE.md` (Claude), or both explicitly. Idempotent, atomic, byte-safe, root-contained; `--surface auto|codex|claude|both`; check and continuation remain read-only. A block one version behind is **STALE, not absent** — `check` says so and exits 5, the continuation packet keeps emitting (and names `protocol_current` / `protocol_stale`) rather than withholding the trail, `establish` upgrades in place, and a hand-edited older body is banked to `<file>.notrest-v2.bak` before it is replaced. |
| **researcher** | Rigorous multi-pass research → a background doc + a decision dossier. |
| **marketresearcher** | Funnel-shaped market research → sizing, competitors, whitespace, an opportunity dossier. |
| **stepbystep** | Turns a goal/docs into a stress-tested, converged, ordered action plan. |
| **actionplan** | Expands a stepbystep plan into a copy-paste-ready runbook (exact commands per host). |
| **critic** | Adversarial red-team of any document — steelman, attack, alternatives, severity-tiered verdict. |
| **explainer** | Layered understanding of any topic — a correct mental model, plain → working → expert layers, the standard misconceptions, verify-it-yourself checks. |
| **decider** | Structures any decision — weighted criteria, evidence per option, sensitivity ("which assumption flips the winner"), pre-mortem, recommendation with reversibility framing. |
| **factcheck** | Claim-by-claim verification against real sources — ✅ CONFIRMED / 🟡 PLAUSIBLE / 🔴 REFUTED / 🔵 MISLEADING / ⚪ UNVERIFIABLE, with daisy-chained sources detected. |
| **watch** | Facts have shelf lives — the calendar-time sibling of factcheck. Pulls a dossier's load-bearing `[cited]` claims into `watch/watchlist.md` (verbatim claim · source · tier · first-verified · last-checked · status · cadence), re-verifies the due ones with the same rigor, and appends a dated **DRIFT REPORT** to `watch/drift-log.md` — HOLDS / DRIFTED / DEAD-SOURCE / UNVERIFIABLE, every run stamping the URLs it actually fetched. A dead source is never mistaken for a refuted claim, drift is never smoothed, and where a scheduled-tasks MCP exists it offers to run the cycle on a cadence — owner-confirmed, never faked. |
| **introspect** | Validated workspace self-reports — a black-box instrument inspired by Anthropic's J-space research: two-layer sealed snapshots (scored tokens + readable glosses) scored against subsequent behavior (verbalized / silent / turnover) with predictive lift vs a context-only control agent. Ships with a real example ledger. |
| **game-forge** | Complete playable games from a short request — fixed-timestep engine templates (browser + pygame), genre playbooks, juice/audio references, and a hard playtest gate: no game ships unrun. |
| **gpt** | Chat-first GPT lane (5.6 family, Codex CLI on your ChatGPT account): `/gpt` just talks to a persistent conversation after a 2-question guided setup — thinking level + how agentic. `--once` one-shots, `--task` background jobs with verified deliverables, `--vs` blind comparisons, `--here` repo-aware mode, and a no-questions `--setup` path for orchestrators. Opinions labeled, never treated as sources. |
| **chatroom** | Shared rooms for AI sessions — any Claude session joins via a tiny script (append-only room file, flock-atomic posts, armed watches as wakes), GPT joins through a persistent-memory bridge (`gpt-bridge --once`, mention-triggered, throttled). Local-machine v1; strict no-secrets rule. |
| **archivist** | Content continuity — the estate's **findings store**: one append-only `archive/findings.jsonl` of validated records (schema, enums, honesty labels, real URLs behind cited links), a cross-project **library shelf** that reads every registered project's store where it lives, and the legacy `oracle-index.md` scan over every dossier, so "what do we already know about X?" costs one `find` instead of a re-spent search budget. It also holds what the estate learned about **working here**: `kind=learning` records tagged `INHERITED` / `RULED` / `LEARNED`, each required to name its evidence and its scope; `open` records for what was *not* tested or could not be verified (with a recheck date, so a question ages on the same calendar as a fact); `alternative` for a road not taken; and `result` records that must name what ran, the command and the exit code, so a test count counts things that actually ran. `index.py card` renders the four boxes — TESTS / OPEN / FINDINGS / LEARNINGS — and the learnings are handed back automatically: into the continuation packet, into every lane's prompt at the spawn gate, and into a one-line router nudge when a prompt touches something a lesson is scoped to. Consult-before-spending; the store is a finding aid, never a source. |
| **graph** | An Obsidian-style file graph of any project — a python3-stdlib scanner walks the repo (`.gitignore` respected) and renders a self-contained, force-directed HTML view of every file and the references between them (wikilinks, markdown links, imports, sourced scripts, estate pointers, agent transcripts), at **zero model tokens**. `domains` partitions any file set into non-overlapping lane assignments — hubs to the seat, components never split — the swarm's TOUCH-ONLY lists, computed not guessed. `register` projects and `all` merges them into one cross-project map — the PM view: one session holding every project at once. The **cockpit** is the live window over all of it — three views, one at a time, each owning the screen — and `serve --always` opts a project in: from then on every session start is told the window exists, probes it with `status` (0 running / 5 down / 6 unopted) and **opens it for the owner** — because a window nobody opens is not a window. |
| **spend** | The token receipt — an append-only `spend/ledger.md` of every observed model spend (subagent counts, workflow totals, gpt tokens-used), graded observed/estimate; `report` prints the per-model split and **exits 4 if Fable ever rode below the seat** — the routing rule, made checkable. |
| **doctor** | The harness's **self-check** — one read-only pass of named PASS/WARN/FAIL checks (the roster grows with each scar — run it for the current list), a fix command on every finding: SKILL.md front-matter a real YAML load would reject (the unquoted `": "` that makes a skill *invisible while the file sits on disk*), manifest + tombstone version pins, skill-count drift across the four places the number is spelled as prose, hook scripts that exist and clear `bash -n` plus rename residue in the SessionStart echo, estate integrity (COORD header, agent ledger, `spend.py report`, compile candidates), repo-vs-clone-vs-installed drift, unanchored gitignore rules that silently un-track a whole skill dir, always-on token budget against its ceiling, app-side plugin packs that shadow this tree, and stale version stamps on rendered surfaces. Every check is a scar from a real defect. Exits 0 / 5 warnings / 6 any fail, `--json` for machines, `--plugin` to inspect what a session is actually running. **Reads only — never repairs, never bumps, never commits.** |
| **eval** | The harness's **law-conformance suite** — a zero-token static pass over the shipped files: dual runtime worker policy (Codex=`gpt-5.6-sol`, Claude=`opus`, inherited forks banned), honesty labels, compiling scanners, append-only ledgers, worker contracts, safe front-matter, safety laws, and the Claude hook adapter. Every FAIL cites file:line and a fix; `behavior --surface codex|claude` is bounded and opt-in. Doctor checks the install; Eval checks the laws. |
| **recap** | The trail, turned into understanding — the **read side of the estate**. Walks `COORD.md`, `COORD-AGENTS.md`, git, `spend/ledger.md` and the dossiers in timestamp order and delivers the project's **decision story**: a narrated timeline, a who-was-consulted table (transcripts existence-checked), ships, costs, open threads — plus a self-contained clickable **decision map** (nodes = rulings / decisions / consultations / ships; edges = led-to / informed-by / reversed). Every claim carries its trail citation; conflicts between sources are surfaced, never smoothed. It derives — it never invents. |
| **draft** | The suite's **outbound verb** — every other skill ends at "you now know / you decided"; draft turns that dossier into the thing you *send* (email · exec memo · slack update · one-pager · status update, each a skeleton with a hard length budget). One law makes it trustworthy: **[fact] vs [framing]** — every factual sentence traces to a source line in a bottom-of-background source-map and keeps its honesty label, while framing choices (what to lead with, what to cut, what tone) are *listed* as choices. Persuasion never upgrades a label: `[estimate]` stays hedged in the final prose, `[unverified]` drops or carries its hedge — never becomes fact. Numbers never invented, quotes never manufactured, recipients never guessed. And **a draft is never sent**: sending is the owner's act in the owner's client, and a draft file is never evidence a message was delivered. |
| **refuter** | The harness's **adversarial reviewer for executables** — the contract that stops "have a lane check the work" from being re-improvised in every prompt. A lane *other than the builder* attacks ONE narrow target under a written brief (artifact inline, isolated scratch dir, hard prohibitions, a numbered attack ladder specialized per target, ~12 tool calls) and answers in a verdict grammar with teeth: **CONFIRMED** needs an exact command and pasted output, **PLAUSIBLE** needs inputs → state → wrong outcome and is explicitly *not evidence*, and a finding with neither **is deleted before returning**. The ladder runs irreversible-path safety → integrity invariants → claim honesty → partial-failure states → test honesty → environment assumptions; severity ranks breaks-irreversible-safety > breaks-claim-honesty > degrades > cosmetic. It also reports what **SURVIVED**, by name. Blast-radius tiered (full refuter for anything that pushes/installs/writes the estate, grep-and-read for docs, nothing for cosmetic), review-the-fix always goes to a different lane, repairs cap at two rounds — and the refuter **never fixes what it finds** and never grades its own prior findings. |
| **director** | Chains the other skills into a pipeline (e.g. `marketresearcher → critic → stepbystep`). |
| **fable-director** | Seats and runs the **"3 DEVS AND A RELAY"** multi-session dev arrangement — a metered Fable/Opus director that applies all code, flat Opus dev/QC lanes handing EDIT SPECS, per-lane blackboard files with token-watch wakes, a QC refuter relay, and a self-carrying rotation ritual. Bundles the V4 protocol of record + a repo scaffolder. Invoke with `/fable-director`. |
| **compile** | The estate's fourth verb — **move repeated work into code**. A python3-stdlib scanner mines `COORD.md`, `COORD-AGENTS.md` and `spend/ledger.md` (optionally session transcripts) for the same job done three or more times and ranks the candidates at **zero model tokens**; a seat-run ritual then reconstructs that job's functional contract from the trail with recap-grade citations, an Opus builder lane emits an isolated runtime under `compile/<slug>/` (runner · typed schemas for the model calls that survive · validators · replay fixtures), an independent refuter attacks it, and the seat runs a **fair benchmark** against the history it came from. Under the owner's 2026-09-05 ruling the pipeline is **automatic end to end, unattended**: the background daemon scans, drafts every ripe candidate at zero model tokens, and — where the owner's authorization also says *unattended* — runs `compile.py auto-run --next`: the oldest drafted candidate built by a headless opus CLI run, gated by its own free fixture, then attacked by a second headless run, benchmarked by script, and adopted only when the fixture, the fair benchmark and the refuter verdict are all green and cited (`ADOPTED` still is not `INSTALLED` — shipping stays a versioned release the owner makes). Spending tokens with nobody watching is bounded first, by rails that are each armed: one estate-wide lock, an owner-set daily token cap the runner refuses to breach, a spend-ledger receipt per headless run (`lane=daemon`, model explicit), a quiet stop with no retry storm on an auth failure, an injectable runner so fixtures never spend a token, two strikes parking a candidate that keeps failing, `NOTREST_UNATTENDED=1` honored by the hooks — no AUTO-BUILD echo and no lane spawns from inside a run — and the ouroboros rule that keeps the compiler from clustering its own receipts into a candidate and paying to compile the act of compiling. One candidate at a time, either way. **The credential is optional and one command:** unattended is opt-in (`compile.py auto --on --unattended`) and nothing else in the plugin needs a credential; the runner uses `CLAUDE_CODE_OAUTH_TOKEN`, else the owner file `~/.notrest/credentials/claude-oauth-token` (0600, dir 0700, a bad mode refused rather than warned), else the CLI's own login — so a logged-in terminal needs nothing. When none works the daemon still drafts for free, writes `BLOCKED` to `pulse/auto-run.status`, and the SessionStart banner says so once a day with the one remedy `compile.py credential --setup`. The token value is never printed, logged or receipted — every surface names only the source it came from. Cheaper-but-worse is a *failed* compile; every metric carries observed/estimate/unavailable provenance; the one-time compilation cost is reported separately and **never amortized**; nothing installs itself — shipping a compiled runtime is a normal versioned release. |
| **agentswarm** | The **fast delegation arrangement**, with a gauge: the seat keeps decomposition, judgment, application, and gates; authorized lanes use the runtime's explicit frontier worker (Codex=`gpt-5.6-sol`, Claude=`opus`). `swarm.py report` bands lane size and reports rework beside it. Codex banks receipts explicitly because Claude's SubagentStop hook does not run there. |
| **tieredswarm** | The three-layer delegation **topology** inside agentswarm — seat → opus lanes → sonnet workers — shipped together with the measured routing gate that mostly refuses it. Apply in order: script it if it is compilable (the material never enters model context at all); **flat solo opus by default** — the measured winner over four rounds on 2026-09-01, ~40% cheaper than the best tiered arm *and* deeper; tier only for payloads that exceed one lane’s context, wide parallelism with a lean fan-in `[unmeasured]`, or local models called as tools `[operator-reported]`. Sonnet workers only where the seat has judged the work bounded and said so in the brief (the 2026-09-01 routing ruling); merging is judgment so the merger stays opus; depth stops at three. The gate is documented before the shape, so the shape is usually not chosen. |
| **mentor** | Seats the **mentor-dev ritual** — two PEER sessions on one chartered room, neither the other’s subagent. The mentor holds the laws, the gates and the estate’s memory and answers in numbered **RULINGS** (`R1..Rn`), each naming the law or record that decided it — a ruling with no cited authority is an opinion wearing a number; gates carry binding **RIDERS** the builder takes into the next task, and the mentor never touches the builder’s tree. The builder holds the code, probes before believing, posts checkpoints before shipping, and owns the numbering. The wire between them is a room the owner reads, so correction is taken back in public. `scripts/mentor.py` does the deterministic half (chartering, escort assembly, checkpoint accounting) and shells the chatroom skill’s `room.py`, so the no-secrets screen is inherited, not copied. |
| **beam** | The lanes keep working after you close the lid — `/beam up` checkpoints the in-flight agent lanes and, where remote isolation exists, respawns the remaining work off this machine; `/beam down` folds the results home. Honest about the physics: **nothing teleports process memory**, so exactly three things survive a checkpoint — the brief, a digest of what the lane has done, and the files it was holding; the context window and the train of thought die there. A respawned lane is told it was *checkpointed*, not paused, so it re-derives instead of confidently narrating work it never did. The estate is the wire: plain files under `beam/<ts>/`, published as a git ref that a remote session clones and commits back to. On Codex the checkpoint is real but remote respawn is unavailable, and must be labeled so. |
| **sessionend** | Captures session state into START-HERE / HANDOFF / STATE / CLAUDE.md so the next session resumes seamlessly. |
| **fable-mode** | The Fable behavioral contract: the ORIENT → PROBE → ACT → PROVE → BANK loop, hard rules — including the **offload model policy** (Fable never rides in a subagent: every offloaded job carries an **explicit model**, and under the owner’s 2026-09-01 ruling the seat **chooses it by the difficulty of the task and declares the choice in the brief** — opus for judgment-bearing work, sonnet for bounded well-specified work, and **when unsure, opus**; never haiku, never `subagent_type: "fork"` (a fork inherits the seat and bills its credit), and omitting the model is a violation, not a default; delegation via agentswarm, refused at the door by `plugins/notrest/hooks/spawn-gate.sh`) — THE FABLE DIFFERENCE (instinct → fable move), a consumer-side verification cookbook, the outage playbook (reroute, stage, never stall), tool-graph craft, and situational profiles. Auto-anchored every session by the SessionStart hook; full contract via `/fable-mode`. |

`oracle` + `sessionend` are bookends: ORACLE loads the foundation at the start, sessionend updates it at the end — together they make sessions continuous. **fable-mode** is the posture in between: the SessionStart hook injects its discipline anchor every session, so reliable working habits are on by default without anyone typing `/fable-mode`.

## Continuity & discipline hooks
- **SessionStart** — self-updates the plugin from git (fire-and-forget `--ff-only`; note: marketplace-cache installs aren't git clones — there the update path is `claude plugin update notrest@notrest`); injects the **fable-discipline anchor** AND the **offload model policy hard rule** (every spawned agent/Workflow lane sets its model explicitly, chosen by the task’s difficulty and declared in the dispatching brief per the owner’s 2026-09-01 ruling — opus for judgment, sonnet for bounded work, opus when unsure; never haiku, never `subagent_type: "fork"`, and omitting the model is a violation, not a default — with agentswarm as the default delegation arrangement) every session; **auto-creates `COORD.md`** — the session coordination ledger (the fable-coord behavior, generalized) — at any git-repo root and nudges reading its tail when it exists; detects `START-HERE.md` / `HANDOFF.md` and adds a resume nudge; detects per-lane `COORD-<LANE>.md` (or legacy `FABLE-COORD*.md`) blackboards and nudges seating the fable-director.
- **UserPromptSubmit** — two cheap per-prompt lines: the COORD reminder (append one honest ledger line when this prompt's work lands), and the **router** — a task-shaped prompt gets one line naming the suite's verb for it (`/notrest:<skill>`, fine to skip deliberately; silent otherwise) — and where no verb fits, or the prompt already named one, that single line may instead quote a **banked lesson** scoped to the paths or skills the prompt mentions).
- **PreToolUse** — the **spawn gate**: an `Agent`/`Task` call that omits its model, names haiku, or asks for `subagent_type: "fork"` is *denied at the door* rather than audited after the burn — the offload law enforced in code, not prose (`hooks/spawn-gate.sh`; `NOTREST_GATE_OVERRIDE=1` permits with a loud receipt, and any malformed payload passes through silently — a broken hook must never break a session). On a lane it *allows*, the same gate does the other half of the learnings loop: it reads the brief for paths and skill names and appends the **scoped LEARNINGS digest** to the prompt the lane actually receives, so a lane starts already knowing what this estate has been corrected on. It also reads the commission's **unfenced** `DONE-WHEN:` block (a fenced one is documentation) into `gates/ACTIVE.md` under a random 8-hex lane key, each line carrying its provenance, with the key handed to the lane in its own prompt tail — so the checks the seat named at dispatch are the checks the Stop gate later runs, retired by key when the lane stops and swept after 24 h if it never did.
- **PreCompact** — reminds that a deliberate `/sessionend` handoff preserves more than automatic compaction.
- **SubagentStop** — when a spawned agent finishes inside a git repo, auto-writes one machine-written line (id · model · last conclusion · transcript path) to `COORD-AGENTS.md` at the repo root, so the session's decision pattern — which agents were consulted and what each concluded — lands in the repo at zero model-token cost (the archivist indexes it; entries point at the full transcripts). It also parses the lane's **return card** — the fixed TESTS / OPEN / FINDINGS / LEARNINGS block every return ends with — and banks each line as a record sourced to that lane, so delegated work banks itself instead of being summarized. What a lane *judged* — its lessons, open questions and alternatives — lands as **`proposed`** and reaches no other lane, no router line and no packet until the seat runs `index.py accept` (or `reject --why`); what it *ran* and *observed* is ungated data. A malformed card banks nothing and says so in the row. And it retires that lane's gate section.
- **Stop** — the **completion gate**: a session cannot say *done* while the checks its own commission declared in `gates/ACTIVE.md` are red, or while a **correction, a refuter defect or a red gate** sits in the ledger with no banked lesson citing it — the block names the failing check or the uncited trigger line and hands back the exact command to fix it. A third trigger catches the quiet one: a claim that something was *not tested* or *could not be verified* with no `open` record behind it — not-tested is a legitimate outcome, not-tested and unrecorded is not. No `gates/ACTIVE.md` and no trigger → the hook does nothing at all; it speaks once (`stop_hook_active`) and fails open with a note, because a gate that fails silently is indistinguishable from a gate that passed.
